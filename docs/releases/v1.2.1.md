碗里的菜将大疆第一代 4G 模块的网络与消息管理放到后台常驻应用中。1.2.1 默认打开网络首页，集中显示信号、运营商、SIM、工作模式、流量和上传 / 下载速度。

- Mac 菜单栏应用与 Windows 系统托盘启动器，启动时不弹终端或网页，关闭管理窗口后继续运行。
- 电脑唤醒后先检查模块网卡；联网正常时保留连接，连续确认断网后才尝试恢复。
- 独立短信与通话页面，新短信、来电和未接来电系统通知。
- 奶油白与绿色界面，支持浅色、深色和跟随系统。

下载对应系统 ZIP 后完整解压。Mac 包用于 Apple 芯片、macOS 13 及以上；Windows 包用于 Windows x64，需正确的 USB 驱动。Mac 使用本机临时签名，未做 Apple Developer ID 公证。详细使用与构建步骤见仓库 README。

验证范围：Mac 已完成构建、签名、后台运行与模块联网验证；Windows 已完成交叉编译和包校验，托盘、通知及 USB 联网仍待 Windows 实机验证。真实短信收发、电话拨打 / 接听与完整休眠恢复周期仍需实机验证。电脑麦克风 / 扬声器的双向通话音频尚未实现。

附件还包含 48 秒横屏 / 竖屏宣传动画与完整素材包：中文合成女声、原创合成配乐、画面字幕、封面、独立音轨和 SRT。宣传画面为示意，不包含实际个人短信或设备标识。
