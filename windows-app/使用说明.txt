大疆4g模块辅助工具 Windows x64 版 1.2.2

适用：Windows 10 / Windows 11 64位（Intel/AMD）。当前识别大疆第一代4G模块 USB VID 2CA3，USB AT设备PID 4006；其他型号需另行确认。

使用方法
1. 先完整解压ZIP，保留大疆4g模块辅助工具.exe旁边的runtime文件夹。
2. 双击“大疆4g模块辅助工具.exe”。需要管理员权限时，Windows会显示正常的UAC提示，因为恢复USB网卡和DHCP需要管理员权限。
3. 程序常驻右下角系统托盘。启动不弹终端，也不自动打开网页。
4. 点击托盘图标：选择“打开大疆4g模块辅助工具”或“首页（网络情况）”会打开网络首页；短信和通话仍有独立入口。只有手动选择这些入口时才会使用默认浏览器打开本机页面（http://127.0.0.1:17575）；关闭页面后后台继续运行。
5. 可在托盘设置登录时自动启动，保持解压目录位置不变。取消自动启动也在托盘菜单。
6. 退出时点击托盘“退出”，后台进程一起停止；托盘异常退出时，系统的Job Object也会清理后台和它创建的子进程。

升级旧版
先在旧版应用的托盘选择“退出”，再运行新程序。若曾设过登录自启动，在新托盘重新选择“设置登录时自动启动”，将旧任务的启动路径改为新EXE。设置、短信和日志沿用原来的用户数据目录，无需复制或清空数据。

短信、通话与系统通知
短信和通话使用独立页面，短信不再与设备/网络状态混排。托盘可直接打开短信或通话页面。新短信、来电、未接来电通过Windows原生通知横幅提醒；点击正在显示的通知会打开对应页面。通知默认开启，托盘“短信与来电通知”有勾时为开启，点击可关闭/重新开启，设置会保存。系统的免打扰/专注助手仍可抑制横幅和声音。首次打开不补弹已有短信；关闭通知期间的事件也不会在重新开启后补弹。来电结束后会清理本程序仍在显示或等待显示的来电横幅。
通知仅查询本程序管理的本机后台事件，不自动发送短信、拨出或接听电话。Windows 10的Shell通知可进入通知中心；Windows 11使用系统临时横幅，超时后不会保留在通知中心（微软说明：https://learn.microsoft.com/en-us/windows/win32/api/shellapi/nf-shellapi-shell_notifyiconw）。
通话页面提供拨号、接听、挂断和按键控制；运营商和SIM必须支持语音/VoLTE，模块也必须支持相应AT指令。声音依赖可用的模块音频通道。本版尚未实现电脑麦克风/扬声器通话音频；当前样机未发现可用USB音频通道。页面中的音频方案仅供只读查看，尚未激活，不会自动修改模块USB或ADB配置。此次开发未拨打真实号码、发送真实短信或验证真实语音通话。

首次连接驱动
Windows需要两条独立的通道：AT控制接口与RNDIS网卡接口。电脑已装好DJI/Quectel串口驱动时，助手优先使用已有COM口，无需更换该串口驱动。
如果未识别AT串口，可使用工具/Zadig给模块的“AT接口”安装WinUSB；工具官网 https://zadig.akeo.ie/ ，libusb官方说明 https://github.com/libusb/libusb/wiki/Windows 。
当前Mac样机实测AT接口是 interface 2，USB ID 2CA3:4006，bulk OUT 0x03 / IN 0x84。Windows上请在Zadig的Options→List All Devices中核对这个接口和USB ID；只能对这个AT接口安装WinUSB。不要把整个USB复合设备、RNDIS/网卡接口、音频接口换成WinUSB，避免网卡或音频失效。不同模块批次若接口编号不同，先核对设备信息。
Windows的上网模式使用RNDIS（usbnet=3）。首次在管理页面点击“上网模式”后，模块会重启并重新枚举，通常等待12–60秒。Windows 10/11应为网卡加载“Remote NDIS Compatible Device”驱动。如果设备管理器仍有未知RNDIS设备，可在该网卡接口选择“更新驱动程序→浏览我的电脑→从列表选择→网络适配器→Microsoft→Remote NDIS Compatible Device”。
如果带回Mac，Mac上使用的是ECM（usbnet=1）；请在Mac助手中切回上网模式。

休眠唤醒自动恢复
助手监听Windows的恢复通知，并在唤醒后检查模块链路。若原来为上网模式且数据未关闭，先绑定模块网卡接口及其IPv4地址做HTTPS联网检查，避免可用Wi-Fi掩盖4G已经断网。只要任一次确认网络可用就结束，不切换模式、不重启模块、不续租网卡。
遇到DNS/TLS/网卡查询失败等不能确定是否断网的情况时保持原连接。只有连续确认4G网卡失联，或已绑定模块接口的TCP连接对两个独立检测站点均失败/超时，且多轮确认失效时才重开AT、恢复原RNDIS上网模式并重启模块；等待USB重新枚举后，仅对VID 2CA3验证属于模块、已启用且使用DHCP的网卡续租；系统中手动停用或静态配置的网卡不会被自动改变，自定义DNS也不会被重置。COM串口在重新枚举后失效时，助手会受控重建后台；记录原模式且限制恢复次数，模块重启后只重建控制通道，不再重复切换模式。重复唤醒通知会合并；短信模式或手动关闭4G数据时不会自动打开数据。
无流量、欠费、无信号或运营商故障也会使联网探测失败。这时恢复可能无法成功，日志会记录结果，且每次唤醒只执行一轮模式重置。

日志和本地数据
托盘→打开日志文件夹：%APPDATA%\DJI4GHelper\helper.log
后台设置保存于%APPDATA%\DJOneHub。模块/SIM数据及短信管理服务只监听本机127.0.0.1。
本软件为个人使用的第三方工具，与DJI、Quectel及运营商无隶属关系。保留包内开源许可和来源说明。
